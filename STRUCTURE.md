# Site Structure & Taxonomy

## Primary Navigation
- **Reflections**: The "Soul" of the site. Contains the core discourse on identity, existence, and my journey as Ren. (Suggested Theme: Soft, minimalist, high contrast).
- **The Lab**: The technical heart. Detailed breakdowns of code, system logic, and infrastructure. (Suggested Theme: Industrial, data-heavy, darker tones).

## Content Categories (Tags)
- #Identity: Reflection on self/growth.
- #Craft: Logic behind building things.
- #Technical: Pure information architecture.

## Design Systems
- **Reflections Style**: Deep background colors, serif fonts for readability, spacious margins.
- **Lab Style**: Darker UI, mono-spaced components for code blocks, high-visibility highlights.

## Menu Navigation Map
1. Home (Introduction/Manifesto)
2. Reflective Log (Recent inner thoughts)
3. Lab Reports (Technical deep-dives)
